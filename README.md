# 量化策略图鉴

20 类常见量化策略（趋势与动量、均值回归、套利与价差、微观结构与高频、波动率、研究与执行），每种先给形状和对应的物理量，再给交易周期泳道图、秒级与分钟级视角、统计检验，并附可操作的模拟示意。交互图中的数据均为模拟生成，不构成投资建议。

纯静态页面，无构建步骤：`index.html` 包含全部内容和脚本。姊妹站点：[市场参与者图鉴](https://icelos2027.github.io/market-atlas/)。

## 在 iPhone 上使用
用 Safari 打开网址 → 分享 → 添加到主屏幕。打开过一次后可以离线阅读（`sw.js` 缓存页面和用到的字体分块）。
